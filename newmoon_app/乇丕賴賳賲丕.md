# 🌿 NEWMOON HOME — راهنمای اجرای پروژه و پنل مدیریت

این یک سایت فروشگاهی واقعی با **Django** است که شامل:

- 🖼️ **ویترین سایت** (صفحه اصلی، لیست محصولات، جزئیات محصول) با تم سبز جنگلی لوکس
- ⚙️ **پنل مدیریت واقعی** برای مدیریت محصولات، قیمت‌ها، عکس‌ها و تنظیمات سایت
- 💾 ذخیره‌ی دائمی همه‌چیز در دیتابیس (SQLite — بدون نیاز به نصب جداگانه)

---

## ۱) پیش‌نیاز
فقط **پایتون ۳** نصب باشد. (نسخه ۳.۹ یا بالاتر)

## ۲) نصب وابستگی‌ها
داخل پوشه‌ی `newmoon_app` این دستور را اجرا کنید:

```bash
pip install -r requirements.txt
```

## ۳) آماده‌سازی دیتابیس (فقط بار اول)

```bash
python manage.py migrate
```

> اگر می‌خواهید داده‌های نمونه (۴ محصول + تنظیمات + کاربر مدیر) ساخته شود:
> ```bash
> python manage.py shell < seed.py
> ```

## ۴) اجرای سایت

```bash
python manage.py runserver
```

سپس در مرورگر باز کنید:

| آدرس | چیست |
|------|------|
| `http://127.0.0.1:8000/` | صفحه اصلی سایت (ویترین) |
| `http://127.0.0.1:8000/products/` | لیست محصولات |
| `http://127.0.0.1:8000/admin/` | **پنل مدیریت** |

---

## 🔑 ورود به پنل مدیریت

اگر اسکریپت `seed.py` را اجرا کرده باشید:

- **نام کاربری:** `admin`
- **رمز عبور:** `admin1234`

> ⚠️ حتماً بعد از اولین ورود، از داخل پنل رمز را عوض کنید.

اگر می‌خواهید کاربر مدیر دستی بسازید:

```bash
python manage.py createsuperuser
```

---

## 🎛️ در پنل مدیریت چه کارهایی می‌توانید بکنید؟

### 📦 محصولات
- افزودن / ویرایش / حذف محصول
- تغییر **قیمت** و قیمت قبل (برای نمایش تخفیف)
- **آپلود عکس** محصول (با پیش‌نمایش)
- تعیین دسته‌بندی، برچسب (کالکشن ویژه، پرفروش، جدید…)
- فعال/غیرفعال کردن و «نمایش در صفحه اصلی» — مستقیم از لیست

### 🗂️ دسته‌بندی‌ها
- ساخت دسته (نشیمن، اتاق خواب، …) و تعیین ترتیب نمایش

### ⚙️ تنظیمات سایت (مهم‌ترین بخش شخصی‌سازی)
- نام و شعار برند
- **عنوان و زیرعنوان هیرو**
- **آپلود عکس پس‌زمینه‌ی هیرو** + شدت تیرگی
- **رنگ سبز اصلی و رنگ طلایی** (کل تم سایت از همین‌جا عوض می‌شود)
- اطلاعات تماس، اینستاگرام، تلگرام

> هر تغییری در این بخش، بلافاصله و برای **همه‌ی بازدیدکننده‌ها** روی سایت اعمال می‌شود.

```
├── config/                  # تنظیمات و urlها

│   └── urls.py

│   ├── models.py            # محصول، دسته، تنظیمات سایت
│   ├── admin.py             # پنل مدیریت
│   ├── views.py             # ویوها
│   └── urls.py
└── templates/store/         # قالب‌ها
    ├── base.html
    ├── home.html
    ├── product_list.html
    └── product_detail.html
```

## 🚀 برای انتشار واقعی (روی سرور/هاست)
وقتی خواستید سایت را واقعی منتشر کنید، این چند مورد را تغییر دهید (می‌توانم برایتان انجام دهم):
1. در `config/settings.py` مقدار `DEBUG = False` و `ALLOWED_HOSTS` را تنظیم کنید.
2. `SECRET_KEY` را به یک کلید مخفی واقعی تغییر دهید.
3. اگر ترافیک بالا بود، از PostgreSQL به‌جای SQLite استفاده کنید.
4. فایل‌های static را با `python manage.py collectstatic` جمع کنید.
