# 📱 اجرای پنل مدیریت NEWMOON HOME روی گوشی (Pydroid 3)

## 🔑 مهم‌ترین نکته که باید بفهمی

پنل مدیریت **یک فایل نیست** که بازش کنی. کار به دو برنامه‌ی جدا نیاز دارد:

| برنامه | کارش چیست |
|--------|-----------|
| 📦 **Pydroid 3** | اینجا فقط سایت را **روشن** می‌کنی (مثل روشن‌کردن موتور). پنل اینجا نیست. |
| 🌐 **مرورگر (Chrome/Brave)** | اینجا آدرس را وارد می‌کنی و **پنل را می‌بینی**. ⭐ |

> ❌ آدرس `http://127.0.0.1:8000/admin/` را **توی Pydroid یا ترمینال نزن!**
> ✅ آن را فقط توی **نوار آدرس مرورگر** بزن.

---

## ✅ ساده‌ترین روش (بدون هیچ دستور ترمینالی)

### قدم ۱ — فایل را در Pydroid باز کن
1. Pydroid 3 را باز کن.
2. از منوی بالا (آیکن پوشه 📂) → برو به مسیر پوشه‌ی `newmoon_app`.
3. فایل **`اجرا_در_پایدروید.py`** را باز کن.

### قدم ۲ — دکمه‌ی پخش را بزن
دکمه‌ی زرد **▶ (پلی)** پایین صفحه را بزن.

> این فایل خودش همه‌کار را می‌کند: Django و Pillow را نصب می‌کند، دیتابیس می‌سازد،
> کاربر مدیر می‌سازد و سرور را روشن می‌کند. فقط کمی صبر کن.

### قدم ۳ — منتظر این پیام بمان
وقتی پایین صفحه‌ی Pydroid این را دیدی:
```
Starting development server at http://127.0.0.1:8000/
```
یعنی سایت **روشن** شد. 🎉

> ⚠️ حالا Pydroid را **نبند**. همان‌طور باز بگذار.

### قدم ۴ — حالا برو سراغ مرورگر
1. از گوشی، **Chrome** یا **Brave** را باز کن.
2. در نوار آدرس بالا، دقیقاً این را تایپ کن:
   ```
   http://127.0.0.1:8000/admin/
   ```
3. صفحه‌ی ورود باز می‌شود. وارد شو با:
   - نام کاربری: **admin**
   - گذرواژه: **admin1234**

🎉 تمام! حالا در پنل مدیریت هستی.

## 📋 آدرس‌ها (همه در مرورگر، نه Pydroid)

| آدرس | چیست |
|------|------|
| `http://127.0.0.1:8000/` | صفحه اصلی سایت |
| `http://127.0.0.1:8000/products/` | لیست محصولات |
| `http://127.0.0.1:8000/admin/` | **پنل مدیریت** ⭐ |

## ❓ مشکلات رایج

**۱) Pydroid گفت `python: not found`؟**
→ این یعنی از **Terminal** پایدروید دستور زدی. از Terminal استفاده نکن!
به‌جایش فایل `اجرا_در_پایدروید.py` را باز کن و دکمه‌ی ▶ را بزن.

**۲) مرورگر می‌گوید صفحه باز نمی‌شود؟**
→ مطمئن شو Pydroid هنوز باز است و نوشته `Starting development server`.
→ آدرس را دقیق `http://127.0.0.1:8000/admin/` بزن (با http، نه https).

**۳) اولین بار نصب Django طول کشید؟**
→ طبیعی است. فقط بار اول کمی صبر می‌خواهد. دفعات بعد سریع است.

**۴) رمز را عوض کردم/فراموش کردم؟**
→ فایل `db.sqlite3` را پاک کن و دوباره فایل اجرا را بزن تا `admin/admin1234` از نو ساخته شود.

## 🟦 اگر Termux داری (روش حرفه‌ای — اختیاری)

در Termux اول پایتون را نصب کن (همان پیامی که خودش داد):
```bash
pkg install python -y
pip install Django Pillow
cd /storage/emulated/0/Download/newmoon_app
python manage.py migrate
python manage.py shell < seed.py
python manage.py runserver
```
سپس در مرورگر: `http://127.0.0.1:8000/admin/`
